# ST Capture Fixtures

These directories hold cross-language S4a captures produced by running the
vendor-neutral ST capture POUs in an IEC runtime and dumping their public outputs.

Each scenario directory contains:

- `meta.json`: the fixed operation list and capture contract.
- `ring.hex`: the 256-byte physical ring image dumped from the ST POU.
- `control.json`: the dynamic control fields dumped from the ST POU.

`ring.hex` and `control.json` are not generated by Rust. They must come from the
ST runtime capture. The Rust validator regenerates the same scenario with the
carriage `EpochProducer`, compares the captured ring bytes and control fields, and
then feeds the captured image through the raw-byte consumer and epoch resolver.

`ring.hex` is plain hexadecimal for exactly 256 bytes, with optional whitespace.
`control.json` contains only the dynamic fields exposed by the ST producer:

```json
{
  "headAbs": 812,
  "oldestAbs": 568,
  "lostCount": 10,
  "runId": 1,
  "epochId": 2,
  "epochFirstAbs": 648,
  "definitionHash": "6e65776861736832",
  "prevDefinitionHash": "6f6c646861736831"
}
```

The validator fills the fixed control-block constants itself: version `2`, caps `0`,
buffer id `1`, and buffer size `256`.
